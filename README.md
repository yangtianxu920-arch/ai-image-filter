# AI 过滤器

一个浏览器扩展（Chrome / Edge），在浏览网页时标记疑似 AI 生成的图片，帮助需要非 AI 素材的人（比如找绘画参考的画师）筛选内容。目前主要适配小红书网页版，Pinterest 和普通网页也能用。

## 使用须知

- **检测结果可能出错。** 会漏判 AI 图，也会把真人作品误判成 AI。
- **仅供个人筛选素材时参考。**
- **禁止把结果当作证据**用于指认、举报、挂人，或用于"AI 对赌"等任何争议和对赌场景。本工具的输出不能证明一张图是或不是 AI 生成的。

## 功能

- 在封面和图片上打角标：红色表示判为 AI，黄色表示疑似，灰色"检查中…"表示还没判完。
- 三种处理方式：只打标记、模糊（悬停查看）、隐藏。
- 小红书笔记详情页可以手动"标记为 AI / 不是 AI"，标记过的作者其他封面会显示"疑似AI"。
- 页面底部显示检查进度，分得清"还在检查"和"检查完了、没发现"。
- 在任意图片或图片链接上点右键，选"用 AI 过滤器检查这张图片"，可以手动检查。

## 判断依据

| 依据 | 说明 |
|---|---|
| 平台的 AI 声明 | 例如小红书的"作者声明：含 AI 合成内容" |
| 手动标记 | 你自己在详情页点的"标记为 AI" |
| 图片元数据 | 仅普通网页：生成工具写进图片文件的信息（C2PA、Stable Diffusion 参数等） |
| 本地模型（可选，默认关闭） | 一个图像分类模型在本机看图判断 |

标题、正文、标签里出现"AI"字样**不作为依据**：教程、讨论、吐槽都会提到 AI，写了不代表图是 AI 生成的。

本地模型的几条固定规则：

- 分数达到 99% 才给红色角标；90%~99% 给黄色提示。门槛不可调。
- 拼图（九宫格等）按格子分别判断。
- 视频封面、白底图最多给黄色提示；太模糊的图不判。

## 安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开"开发者模式"。
3. 点"加载已解压的扩展程序"，选择本仓库的文件夹。
4. 如需模型识别，点扩展图标，勾选"用模型识别图片本身"。首次会下载约 190MB 的模型。

## 已知局限

- 模型对器具类图片（刀剑、饰品等）识别较差；偏柔和的写实人像容易漏判；游戏或 3D 渲染的角色图容易误判。
- 盖了满屏水印的 AI 图可能漏判。
- 只能在电脑浏览器里用，不支持手机 App。
- 网站改版后页面适配可能失效。
- 准确度只在几十张图的小样本上测过，没有正式的评估数据。

## 隐私

图片只在本机判断，不会上传，也不会用于训练任何模型。扩展发出的网络请求只有：首次从 Hugging Face 下载模型、从图片原网站重新读取图片（不带登录信息）。手动标记的记录只保存在浏览器本地。

## 开发

```
node test/detect.test.js
```

主要文件：

- `src/content.js`：页面扫描、角标、进度提示
- `src/infer.js`：模型推理、拼图切分、清晰度和白底检测
- `src/background.js`：后台脚本、右键菜单、元数据检查
- `offscreen/`：运行模型的离屏页面
- `popup/`：设置弹窗

## 第三方组件

- [onnxruntime-web](https://github.com/microsoft/onnxruntime)（MIT），位于 `vendor/ort/`
- 检测模型 [SoldadoXara/ai-image-detector-deploy-ONNX](https://huggingface.co/SoldadoXara/ai-image-detector-deploy-ONNX)（Apache-2.0），运行时下载，不包含在本仓库中
